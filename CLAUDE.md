# Claude Code Notes

This repository contains a Claude Code project skill at `.claude/skills/seo-content-optimizer/`.

For SEO, GEO, and AEO work:

- Use the project skill when the task involves page audits, article optimization, metadata rewrites, FAQ creation, schema recommendations, internal-link improvements, review-page analysis, or tutorial optimization.
- Treat the repo-root `SKILL.md` as the canonical workflow.
- Load repo-root files under `references/` as needed.
- Default to a quick audit unless the user explicitly requests a full audit.
- Prefer concrete fix packs over generic commentary.
- Check for first-hand experience, information gain, entity coverage, and trust signals before recommending content changes.
- Prefer cluster-based internal-link recommendations over isolated link ideas.
- Recommend schema only when the visible page supports it honestly.
- Do not invent claims, stats, testimonials, credentials, or first-hand experience.
