# SEO Content Rewrite

Optimize a page, article, or landing-page draft for SEO, GEO, and AEO.

## Instructions

1. Read the repo-root `SKILL.md`.
2. Load any needed repo-root references from `references/`.
3. Determine the page type and likely search intent.
4. Improve structure, metadata, answer-first clarity, internal links, FAQ opportunities, and schema recommendations.
5. Preserve factual accuracy and brand meaning.
6. Avoid invented claims or proof.

## Output

- Revised title
- Revised meta description
- Recommended H1
- Answer-first intro
- FAQ additions
- Internal-link ideas
- Schema recommendation
- Short rationale
